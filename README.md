## 원본 보존과 실제 구현 분석

사용자가 제공한 바탕 화면 원본은 수정하지 않았습니다. `legacy/자영업자로_살아남기_프로토타입.html`에 그대로 복사했습니다.

실제 원본 기능: 자기자본·대출·생활비 선택, 치킨·카페·편의점·분식 4개 업종, 3개 상권, 예시 창업비용·고정비, 연 5% 이자·만기 원금상환, 최대 36개월 시뮬레이션, 6·12·18·24·30개월 선택 이벤트, 월별 현금 그래프, 부족 시 중단·자발적 종료, 종료 시 보증금·대출 정산, CSV 장부.

원본에 없던 기능: 브랜드별 공개 평균매출을 활용한 키워드 선택, 점주 노동시간 기록, 세금·감가상각, 원금 분할상환, 폐업 시설 처분·철거·해지 비용, 현실 기사, 공식 통계 비교. 원본의 `ownerHours`는 불리언만 기록했고 실제 시간 계산은 없었습니다.

`scripts/upgrade.mjs`는 원본 HTML의 주요 ID·레이아웃·카드·장부·CSV 흐름을 보존하고 확장합니다. 프로필 4종, 지역 3종, 계절변동 함수와 5개 이벤트의 조건·선택 효과는 `dist/simulation.js`에 재사용했습니다. 새 변수들을 끄면 원본 월별 현금공식으로 돌아가는 회귀 테스트를 포함합니다. HTML 재생성은 `node scripts/upgrade.mjs`입니다.

확인·게시: 중앙일보 공식 이슈패키지와 녹두호프·월세·배달·가맹계약·과잉경쟁 기사, 중앙일보 제공 Daum 고령화 기사, 2024/2026 적용 최저임금, 2024/2025 폐업 사업자 수(중기부가 재공표한 국세통계 반올림 집계), 2025-10-23 공표 기업생멸행정통계의 2023년 생존 기준 잠정치, 쿠팡이츠 공식 요금 정책과 2026 포장 정책 공지, 2026 원스톱폐업지원 공고.

배달 기사는 URL·제목을 확인했지만 본문 접근이 제한되어 개인 발언을 인용하지 않았습니다. 고령화 기사의 중앙일보 개별 URL은 미확보로 중앙일보 제공 Daum 전재본과 공식 이슈패키지를 연결했습니다. 기사의 월·일을 원문에서 확인하지 못한 경우 `2024-09`로 표기하고 정확한 날짜를 임의 생성하지 않았습니다.

미확보/미완료: 실제 브랜드별 정보공개서 전체 원자료와 브랜드별 창업비·계약조건, 같은 정의의 최신 자영업자 수·비중·연령별 집계, 개인사업자 대출·연체율, 신규 사업자, 원재료·상가임대료 시계열, OECD 동질 비교, 요기요의 최신 약관. 치킨·카페·편의점 선택지는 공정위 공개 목록의 2024년 실적을 기준으로 했고, 분식 선택지는 공개 집계 사이트의 상위 목록으로 별도 표시했습니다. 이 항목은 화면의 데이터 검증 상태에서 공개하며 숫자를 생성하지 않았습니다.

기업생멸통계의 과거 값은 최신 자료의 소급 정비 계열을 사용합니다(2022년 5년 생존율 34.8%). 2024년 말 발표의 34.7%를 최신 36.4%와 그대로 빼지 않습니다. 2024년 말에 발표된 이전 자료는 기획 보도 시점인 9월에는 아직 공개되지 않았으므로 ‘기사 당시 알던 통계’라고 표시하지 않습니다.

통계·기사 정보는 `dist/content.js`와 `data/` JSON에 구조화되어 있습니다. 원문 전문·이미지·영상은 저장·재사용하지 않았습니다. 전체 출처는 웹사이트 하단에 있습니다. 최신 여부를 확인하지 못한 항목은 ‘최신 공식 실적’으로 단정하지 않습니다.

## 계산의 범위

금액은 만원. 매출·운영비는 VAT 제외. 시설비 60개월 감가상각. 영업손익에서 이자·원금·생활비는 제외합니다. 세후 손익에서 이자·소득세를 한 번 차감합니다. 현금에서는 세후 손익에 감가상각을 더하고 원금·VAT 실효 유보·생활비를 차감합니다. 배달 결제료와 홀 카드료는 다른 매출 베이스에 적용합니다.

소득세는 월 단위 실효율 가정이며 연간 누진·손실 이월·매입세액공제·정확한 VAT 신고 계산이 아닙니다. VAT 실효율은 현금 유보를 표현하는 단순 가정입니다. 일시 이벤트 비용의 세금 절감 효과는 생략합니다. 퇴직금은 인건비에 포함된 예산으로 단순화하며 권리금 회수는 0입니다. 2026 조건을 고정한 가상 36개월로 미래의 임금·금리·매출 전망이 아닙니다.

청산 회수액과 회수율은 생활비 인출 후 잔여 자산 기준입니다. 정상 36개월 종료는 실제 폐업으로 판정하지 않지만 비교용 청산 가정을 적용합니다. 점주 노동시간당 사업소득은 자본 수익을 포함할 수 있고 법정 임금이 아닙니다.

## 파일

- `dist/index.html`, `editorial.css`: 원본을 확장한 인터페이스와 모바일 레이아웃
- `dist/simulation.js`: DOM에 의존하지 않는 계산 엔진
- `dist/app.js`: 게임·장부·현실 추천·인터랙티브 그래프
- `dist/content.js`: 기사·공식 통계·검증 상태·방법론
- `legacy/`: 원본의 변경 없는 복사본
- `data/`: 출처·구조화 데이터·가정값
- `tests/`: 계산 및 데이터 무결성 회귀 테스트
- `scripts/browser-qa.mjs`: 실제 Chromium 데스크톱·모바일 전체 흐름 검증 (이 PC의 번들 Playwright 경로 사용)
- `artifacts/`: 브라우저 검증 기록과 스크린샷 (배포에 포함하지 않음)

사이트는 중앙일보의 공식 서비스가 아닌 독립적인 재구성물입니다.
